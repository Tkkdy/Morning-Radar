DeepSeek 开放 App 全家桶能力 API，并开源演示对话客户端

DeepSeek 官方更新文档宣布，将 App（含网页端）对话服务中的联网搜索、文件输入、阅读链接、语音交互及安全等能力开放给开发者：在原有 API 中开启对应参数即可获得相关对话功能，工具调用与上下文拼接由服务端完成。其中，deepseek-flash 模型已在 Messages、Responses 与 Chat Completions 接口下支持联网搜索；文件输入支持 PDF、Office、图片等格式，先提取文本或解析图文混排内容，再拼入上下文；deepseek_read_url 工具可自动识别消息中的链接并抓取网页内容；开启安全校验参数后提供基础风控，命中风险时返回拒答标识。上述底层能力及语音能力也可作为独立接口单独调用，包括 Search、Fetch、OCR、ASR、TTS。此外，DeepSeek 基于这些 API 构建并开源了一个演示用对话客户端，支持导入 DeepSeek 历史对话。

为什么重要：此次更新实质上是把 DeepSeek App 侧的对话增强能力（搜索、文件解析、链接阅读、风控、语音）产品化为 API 能力，有望降低开发者自行实现工具调用与上下文拼接的成本。

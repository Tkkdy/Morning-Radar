Hugging Face Transformers 同日连发 v5.16.0 与 v5.16.1，新增 Qwen4-Exp、GLM-5.3-Flash 支持

2026 年 8 月 26 日，Transformers v5.16.0 发布，新增 Qwen4-Exp 模型支持，Qwen4-Exp 基于 Qwen3.5 的混合文本与多模态架构，包含 GatedResidual、Qwen Sparse Attention 和 Per-Layer Embedding 三个关键组件；发布说明还提及 GraniteSpeech5 与 Step3p7 支持。同日随后发布的 v5.16.1 新增 GLM-5.3-Flash 多模态模型支持，该模型总参数 320B、活跃参数 18B，采用混合稀疏与线性注意力架构，并使用 Manifold-Constrained Hyper-Connections (mHC)，据称在基准测试中优于 GLM-5.2 且价格仅为其十分之一；v5.16.1 还修复了张量并行 API 的向后兼容性问题，并固定了 ESMFold2 的内核提交和仓库路径。

当前判断：GLM-5.3-Flash 宣称以十分之一价格达到接近 Claude Opus 4.8 的性能，若第三方验证属实，可能冲击低成本多模态模型市场。

为什么重要：Transformers 库连续更新反映 Hugging Face 对高效长上下文、多模态和轻量语音模型支持的快速跟进。GLM-5.3-Flash 自称接近 Claude Opus 4.8 且价格极低，可能影响开发者对低成本多模态模型的选择。

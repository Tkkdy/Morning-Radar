Ollama v0.40.16 预览 Ricursive Intelligence 的 65B 编程模型 Ripple Preview

Ollama 发布 v0.40.16，引入来自 Ricursive Intelligence 的 65B 稠密模型 Ripple Preview，面向 agentic coding，可通过 `ollama run ripple-preview` 运行。同版本中，Qwen3.8 Flash Next 在 Apple silicon 上的内存占用减少约 27 GiB；`ollama launch claude` 现在总是将 Claude Code 路由到所选模型；`/v1/responses` 遵循 `truncation` 参数、默认不再静默截断；`/v1/models` 在未安装模型时返回空列表；并增加对 Windows on ARM 的 CUDA 13.5 支持，同时更新 llama.cpp。

为什么重要：此次发布同时推进模型生态与运行时兼容性：既接入新的第三方预览模型，也调整了 Claude Code 路由、OpenAI 兼容接口截断行为与 ARM 平台 CUDA 支持，影响本地部署的模型选择与资源门槛。

已验证事实

  • 该版本的 Features 包含：组织 webhook 端点接受 user_profile.program_status_updated；新增 claude-fable-5-2 和 claude-mythos-5-2；用量与成本报告新增父组织过滤与分组；Admin API 写方法新增 sandbox_egress_restricted 错误；新增 user_profile.program_status_updated webhook 事件。

  • parse 相关修复：在结构化输出 schema 中保留 const，并移除 const 与 enum 旁的 type。
  • 该版本还包含若干 Chores：删除部分错误详情类型并更新描述；说明 work heartbeat 何时不比较其值；添加本仓库 review 规则；删除错误类中的两条注释。

  • Release 条目未给出 claude-fable-5-2 与 claude-mythos-5-2 的模型细节或可用范围，需结合后续官方文档判断。

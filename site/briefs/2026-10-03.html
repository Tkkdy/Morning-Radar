modelcontextprotocol/python-sdk 发布 v2.3.0

GitHub 上 modelcontextprotocol/python-sdk 发布 v2.3.0，作者为 maxisbey，发布时间为 2026-10-02T22:02:27Z。

为什么重要：v2.3.0 的定位是修复版本，但同时要求 `httpx2>=2.10.0`，使用方若把 httpx2 固定在 2.10 以下可能受此依赖提升影响。

已上线
GitHub · modelcontextprotocol/python-sdk · Release 主来源 Release 发布于 2026-10-02
查看详情

已验证事实

  • 安装命令为 `pip install -U mcp`，文档地址为 https://py.sdk.modelcontextprotocol.io/。
  • 该版本以修复为主，另新增三个选项，并包含若干行为变更。
  • 行为变更：`httpx2>=2.10.0` 现在成为必需依赖（#3600），此前要求为 `>=2.5.0`；这是新的 `max_sse_event_size` 选项所需。
  • 行为变更：带有无效 `x-mcp-header` 注解的工具会在注册时失败（#3620），`@mcp.tool()`、`add_tool` 和 `Tool.from_function` 会抛出 `InvalidSignature`，并指明工具名与问题。
  • 行为变更：除普通 `str`、`int` 或 `bool` 参数外（包括 `str | None`、`float`、列表和枚举），以及非合法 token 的 header 名称、大小写不同但名称相同的两个 header，都会被拒绝。
  • 行为变更：不再发送空的 `_meta` 和 `params`（#3628）；在 2025-11-25 及更早连接上，2.x 曾对每个请求发送 `"_meta": {}`，现已省略。
  • 行为变更：没有游标的 `ping` 和列表请求不再携带 `params` 成员；接收侧 `ctx.meta` 为 `None` 而非 `{}`，中间件对无参数请求看到 `ctx.params` 为 `None`。
  • 行为变更：`initialize` 在未配置 `experimental` 时不再发送该字段（#3614）；此前会发送 `"experimental": {}`，而 `server/discover` 已省略。
  • 行为变更：`Mcp-Param-*` 校验按名称查找工具（#3630）；`MCPServer` 不再为每次 `tools/call` 运行 `tools/list`，中间件不再看到该额外请求。
  • 行为变更：交互式 OAuth 登录不再计入请求超时（#3635）；超时在 `OAuthClientProvider` 等待 `redirect_handler` 和 `callback_handler` 时暂停。
  • 新增：`streamable_http_client` 和 `StreamableHttpParameters` 上的 `max_sse_event_size=`，默认保持每个 SSE 事件 1 MiB，可调大或传 `None` 以支持更大的工具结果（#3600）。
  • 新增：`MCPServer(subscriptions=False)` 停止提供 `subscriptions/listen`，并将 `listChanged` 和 `subscribe` 通告为 false（#3626）。
  • 新增：`Server(get_tool_input_schema=...)` 允许底层服务器在不运行 `tools/list` 处理器的情况下，为 header 校验提供工具的 schema（#3630）。
  • 新增：`Client.call_tool` 在收到 `HeaderMismatch`（-32020）拒绝后重新列出工具并重试一次（#3627）。
  • 修复：`ctx: Context[AppState]` 可在 prompts 和资源模板上使用，不再仅限于工具（#3624）。
  • 修复：显式的 `"structuredContent": null` 会按输出 schema 校验，而不是被当作缺失处理（#3621）。
  • 修复：在进程内 `Client(server)` 上，抛出异常的 `progress_callback` 不再导致调用失败（#3623）。
  • 修复：客户端 OpenTelemetry span 记录 JSON-RPC 错误响应；使用 `mode="auto"` 连接没有 `server/discover` 的服务器时，探测会产生一个 `ERROR` span（#3629）。
  • 修复：`stdio_client` 在 Windows 上于事件循环之外解析可执行文件（#3510）。
  • 文档：新增 Cancellation 和 Header parameters 页面，以及一个中间件教程；全部十二种翻译已刷新（#3636）。

分析

  • 把无效 `x-mcp-header` 注解从“服务器启动、客户端静默丢弃工具”改为注册时报错，属于可观测性提升，但会改变现有工具的注册行为。
  • 不再发送空 `_meta`/`params`，以及 `ctx.meta` 变成 `None`，对读取或判断这些字段的客户端和中间件代码构成兼容性变更。
  • OAuth 登录不再触发请求超时，修复了 `Client(mode="auto")` 在登录超过 10 秒时落到 `2025-11-25` 的问题。

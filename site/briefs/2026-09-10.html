Cloudflare 发布 Automatic Key Exchange，用于探测支持 TLS 1.3 的客户源站所支持的密钥协商算法，并在连接源站时优先采用安全性最高的算法；只要源站支持，就优先使用后量子连接。Cloudflare 称该功能面向每日 450 亿次连接（且仍在增长）的场景。

已验证事实

  • Hugging Face 的 huggingface/transformers 仓库发布了 Release v5.17.0。
  • v5.17.0 新增模型支持包括 HYV4、VibeVoice、NeoMME 和 Fun-ASR-Nano。
  • HYV4 方面，Hy4-Preview 是一个 780B 参数的混合专家（MoE）语言模型，每个 token 激活 49B 参数。
  • 据发布说明，HYV4 的每个 MoE 层包含 256 个路由专家加一个始终激活的共享专家，每个 token 路由到其中 8 个专家，上下文窗口为 1M tokens。
  • 据发布说明，HYV4 架构包含四项特性：Multi-head Latent Attention（MLA）、DeepSeek Sparse Attention（DSA）、带可学习 attention sinks 的 Gated MLA，以及 Independent Hyper-Connections（iHC）。
  • 据发布说明，HYV4 实现不执行多 token 预测（MTP）层，但发布的 checkpoint 保留这些权重以便其他运行时用于投机解码，加载时被忽略。
  • HYV4 由 @ArthurZucker 通过 PR #48473 添加。
  • 据发布说明，VibeVoice 是一个在 LLM 结构内采用 next-token diffusion 方法、用于合成高保真多说话人长语音的框架，适用于播客和多参与者有声书等音频内容。
  • VibeVoice 由 @pengzhiliang 通过 PR #40546 实现。
  • 据发布说明，NeoMME 是来自 H Company 的高效 260M 和 800M 参数多模态原生多语言基础编码器系列，在单个双向 Transformer 编码器中处理多语言文本 token 和原始图像 patch，无需单独预训练的视觉塔或因果语言模型。
  • 据发布说明，NeoMME-Retriever 是从 NeoMME 骨干微调的模型，用于视觉文档检索，结合后期交互与稠密目标，接收文本查询和文档（文本或页面截图），输出用于 MeanMaxSim 评分的多向量嵌入以及用于余弦相似度的均值池化嵌入。
  • NeoMME 和 NeoMME-Retriever 由 @tonywu71 通过 PR #47992 添加。
  • 据发布说明，Fun-ASR-Nano 是阿里巴巴 DAMO Academy 的 FunAudioLLM 团队开发的 800M 参数端到端语音识别模型。
  • 据发布说明，Fun-ASR-Nano 在中、英、日 ASR 基准上达到 state-of-the-art 性能，同时规模显著小于同类模型。
  • 据发布说明，Fun-ASR-Nano 支持中文、英文和日文，包括 7 种中文方言和 26 种地区口音，支持热词定制，并原生输出标点，无需单独的标点模型。
  • Fun-ASR-Nano 模型通过 PR #46180 添加。

分析

  • v5.17.0 一次性纳入文本 MoE、语音合成、多模态检索编码器和语音识别四类模型，说明 Transformers 的模型接入范围继续向多模态与语音方向扩展。
  • HYV4 同时采用 MLA、DSA 和 iHC 等注意力与残差路径改造，反映出大模型架构层面对长上下文（1M tokens）与推理效率的持续优化取向。

  • Fun-ASR-Nano 以 800M 参数主打中英日 ASR，并在发布说明中强调相对同类模型的规模优势，显示小参数规模端到端语音识别仍是竞争方向。

不确定性

  • 发布说明未给出 HYV4、VibeVoice、NeoMME、Fun-ASR-Nano 具体基准测试数值或对比结果。
  • 发布说明未说明 HYV4、NeoMME、Fun-ASR-Nano 相关 checkpoint 的许可协议与可用范围。
  • 发布说明未提供 VibeVoice、NeoMME、Fun-ASR-Nano 的完整参数规模以外的训练数据与训练细节。
  • 发布说明中 HYV4 上下文窗口为 1M tokens 等能力描述来自官方发布文本，尚无独立复现验证。

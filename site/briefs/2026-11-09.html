已验证事实

  • 该版本说明标题为 Highlights 的部分提出：可通过 agents.classic 导入保留的 v0 运行时，以便在原生执行之外使用 Classic 工作流。
  • 版本说明称新增可通过 CustomStorage 实现持久化的根级 Session，用于将对话保存在自有存储中。
  • 版本说明称新增面向原生 agent 的语音与托管工具，包括 FileSearch、CodeInterpreter 和 ImageGeneration，需通过兼容的 Responses 提供商使用。
  • 版本说明称新增对上下文、完成过程与用量控制的能力：可转换模型输入、在压缩时保留选定上下文、审阅拟定答案，并限制观察到的根级用量。
  • 升级条目说明：新 Environment 默认 write_policy='strict'，需要兼容的 Linux 或 macOS 执行器；原有远程策略（包括 Windows 执行器）需显式设置 write_policy='legacy' 并保持 writable_roots=None。
  • 升级条目说明：捆绑模型目录将 gpt-6-astra、gpt-6.1-sol 和 gpt-5.6-sol 的默认 reasoning effort 从 low 改为 medium，如需沿用需显式设置 model_settings={'reasoning_effort': 'low'}。
  • 升级条目说明：MCP 审批模式重命名，approval_mode='auto' 改为 'native'，'approve' 改为 'preapproved'，旧值会被拒绝。
  • 升级条目说明：NativeAgents.before_step 现在接收单个 ChildStepContext（含 context、child、step_index），根级 before_step 回调签名不变。
  • 升级条目说明：ElicitationRequest 现为 FormRequest | UrlRequest 的联合类型，分别通过 FormRequest.reply()/respond() 与 UrlRequest.reply_url_accept()/accept_url() 处理。
  • Added 部分说明：SessionStore、SQLiteSessionStore 和 CustomStorage 可持久化根级历史与自动 Python 工具结果；该初始配置不包含原生工具、Environments、子级、规划工具、生成代码执行、手工工具和可移植检查点。
  • Added 部分说明：SQLiteSessionStore 要求单主机与本地 POSIX 文件系统；本地配置与自定义存储可报告不确定的根级调用以供显式核对，且不会自动重放这些效果。
  • Added 部分说明：托管工具需要 API-key 提供商和兼容的标准 Responses 模型，排除 Responses Lite 与 Codex login；托管网页搜索增加域名与位置控制并保留引文。
  • Added 部分说明：新增 Agent.transform_context、before_compact、before_complete 等上下文与完成钩子；被拒绝的文本可能已经流式输出并保留。
  • 该仓库当前约 30561 stars、5016 forks、49 open issues，24 小时 stars 增量 12。

MCP Python SDK v2.0.0rc1 发布，引入多项破坏性变更

MCP Python SDK 首个 v2 候选版 v2.0.0rc1 发布，可通过 pip install mcp==2.0.0rc1 安装。版本包含多个破坏性 API 调整（如 client/cache 参数变更、移除部分旧接口），并与 2026-07-28 规范修订对齐；改进了 stdio 服务器 stdout/stderr 分离、Streamable HTTP 请求体大小限制、工具校验性能。

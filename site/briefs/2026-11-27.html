pydantic-ai 发布 v2.76.0：实时会话支持工具更新，并对 gemini-2.5 系列发出弃用警告

pydantic/pydantic-ai 于 2026-11-26 发布 v2.76.0，发布说明由作者 dsfaccini 提交。

为什么重要：v2.76.0 是一个兼容性变更较多的版本：实时会话的工具更新能力与 `RealtimeInput` 类型的扩展改变了类型层面的契约，而 `read_file` 的 offset 语义从 0 起始改为 1 起始，属于会影响现有 Python 调用方的行为变更。

已上线
GitHub · pydantic/pydantic-ai · Release 主来源 Release 发布于 2026-11-26

不确定性：`DeprecatedModelWarning` 中给出的替换模型具体是哪一个，输入摘要未说明。

查看详情

已验证事实

  • 该版本通过 `RealtimeModelProfile.supports_tool_updates` 与 `UpdateTools`，使实时会话能够在会话中途向支持工具更新的模型揭示工具（PR #12440）。
  • `RealtimeInput`（`RealtimeConnection.send` 接受的联合类型）新增 `UpdateTools`，`DEFAULT_REALTIME_PROFILE` 新增 `supports_tool_updates: False`；会话仅向模型 profile 设置了 `supports_tool_updates` 的连接发送 `UpdateTools`。
  • 对 `RealtimeInput` 的穷尽匹配（`assert_never`）将不再通过类型检查，需要处理 `UpdateTools` 或对其抛出异常。
  • 经 `GoogleModel` 或 `GoogleInteractionsModel` 向 `gemini-2.5-pro` 与 `gemini-2.5-flash` 发出的请求现在会发出 `DeprecatedModelWarning`（一个 `UserWarning`）；将警告视为错误的代码（如 `filterwarnings = error`）会在这些请求上失败（PR #14679）。
  • Pax 中新增双击选中单词、三击选中整行的功能（PR #14558）。
  • `pydantic_ai_pax.ui.prompt.prompt_selection` 中的 `Selection.feed`、`span`、`highlight` 和 `text` 新增参数：`feed` 以 `now` 接收按下时间，`span` 以已绘制的 `frame` 和软换行标志 `joins` 取代 `width`，`highlight` 与 `text` 接收 `joins`。
  • Pax 新增 `/computer-use` 桌面沙箱（PR #14564）。
  • Pax 插件状态段现在除 `str` 外还可返回 `StatusLink`，状态行将其显示为可点击链接（PR #14564）。
  • 为每个模型提供商新增 `pydantic-ai-pax` extra，并新增 `all`，默认安装 Google SDK（PR #14614）。
  • `pydantic_ai_pax.cli.self_update.PACKAGES`（`/update` 重新安装的包）现在请求 `pydantic-ai-slim[anthropic,google,mcp,openai]`，与 Pax 默认安装（现已包含 Google SDK）一致，无需迁移。
  • 当能力在运行中途裁剪历史时，运行新增的每条消息都会保留在 `result.conversation` 中（PR #13211）。
  • `FileSystem` 的 `read_file` 的 `offset` 改为 1 起始索引（PR #13250）；从 Python 调用 `FileSystemToolset.read_file(..., offset=N)` 或显式传入 `offset` 构建 `ReadFileArgs`、`ReadFileCallPart` 时现在提前一行开始，`offset=0` 会报错。

分析

  • 针对 gemini-2.5-pro 与 gemini-2.5-flash 的弃用警告表明上游模型支持正在迁移，但在替换模型明确之前，仍可通过过滤警告或设置 `profile={'deprecation': None}` 继续使用。

不确定性

  • 本次发布未说明 `gemini-2.5-pro` 与 `gemini-2.5-flash` 弃用警告的最终移除时间表。
实体：pydantic、pydantic-ai、Pax、GoogleModel、GoogleInteractionsModel产品：pydantic-ai、pydantic-ai v2.76.0、pydantic-ai-pax主题：ai_coding、open_source_ai

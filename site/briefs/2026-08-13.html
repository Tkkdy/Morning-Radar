pydantic-ai 修复高危 XSS 漏洞并新增实时语音功能

pydantic-ai v2.28.0（2026-08-11）修复了一个高危漏洞：开发 Web 聊天 UI（Agent.to_web()、clai web）的聊天端点未检查请求 Content-Type，导致跨源请求可在无 CORS 预检的情况下到达端点并触发 agent 执行工具。该漏洞编号为 GHSA-h4xc-3qfq-jf93，已在 v2.28.0 和 v1.107.4 中修复。新增功能包括通过 Agent.realtime() 支持实时语音转语音，添加 Crusoe provider，以及浏览器 WebRTC + 服务器 sideband 支持。v1.107.4 还修复了低危漏洞 GHSA-3gh4-cghq-f8v4 和重试提示内容遮盖问题。

当前判断：pydantic-ai 的 GHSA-h4xc-3qfq-jf93 漏洞暴露了本地开发 Web UI 的常见攻击面，修复后开发者将更重视 Content-Type 检查，但该模式可能在其他类似工具中重复出现。
当前判断：pydantic-ai 的 GHSA-h4xc-3qfq-jf93 漏洞暴露了本地开发 Web UI 的常见攻击面，修复后开发者将更重视 Content-Type 检查，但该模式可能在其他类似工具中重复出现。

为什么重要：该安全漏洞被评为高危，攻击者只需在开发者浏览器中打开恶意网站即可触发本地 agent 执行工具，可能导致敏感数据泄露或系统被控制。修复要求 Content-Type: application/json 可有效阻止此类跨源攻击。实时语音转语音功能的加入使 pydantic-ai 能构建端到端的实时语音 agent。

OpenAI Python SDK v3.0.0 发布，默认 HTTP 客户端迁移至 HTTPX2

OpenAI Python SDK v3.0.0 于 2026 年 8 月 12 日发布。HTTPX2 现在是默认 HTTP 客户端，`httpx` 不再自动安装。使用自定义 HTTPX 客户端、传输或配置对象的应用必须迁移到 HTTPX2 等价物，或使用临时的、仅运行时的旧版 HTTPX 逃生舱。迁移指南位于 https://github.com/openai/openai-python/blob/main/httpx2.md。该版本包含一个破坏性变更：API 迁移到 HTTPX2（PR #3594）。

后续事件

相比此前：从此前的 openai-python v2.54.0 到当前 v3.0.0，默认 HTTP 客户端由 httpx 切换为 HTTPX2，并引入破坏性变更 PR #3594；使用自定义 HTTPX 客户端、传输或配置对象的应用需迁移或使用旧版逃生舱。

此前：2026-08-12 · OpenAI 发布 openai-python v2.54.0

为什么重要：迁移到 HTTPX2 表明 OpenAI 正在采用更新、可能更高效的 HTTP 客户端库，以提升性能和未来兼容性。引入临时逃生舱可减轻依赖自定义 HTTPX 配置的现有用户的迁移痛苦。

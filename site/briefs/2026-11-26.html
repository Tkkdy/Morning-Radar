pydantic-ai 发布 v2.75.0，调整工作区文件权限与模型回退错误处理

pydantic/pydantic-ai 发布 v2.75.0，发布日期为 2026-11-25，发布说明由 dsfaccini 提交，对应提交 003d60f6。

为什么重要：本次发布的重点在权限边界收紧与错误语义细化：低于 operator 权限的工作区文本不再直接进入模型指令，改为由模型通过文件工具主动读取，这降低了低权限内容被当作指令注入的风险。

已上线
GitHub · pydantic/pydantic-ai · Release 主来源 Release 发布于 2026-11-25

不确定性：发布说明未说明该版本是否已正式推送至 Python 包索引，也未给出具体的安装或升级命令。

查看详情

已验证事实

  • 兼容性变更：低于 'operator' 权限的工作区文件内容不再进入 RepoContext、Skills 与 Memory 的指令；RepoContext 改为向模型指出工作目录文件供其用文件工具读取，Skills 通过 list_skills 和 load_skill 工具提供技能而非 load_capability，Memory 将该快照归属到 MEMORY.md。'operator' 权限（默认）的文件行为不变。
  • 发布说明称持久化运行会在启动时记录额外的 realpath 工作区调用，建议等待在途运行结束，或使用 Temporal worker versioning 或新的 DBOS 应用版本后再升级。RepoContext(autoload_instructions=False) 配合嵌套指令文件时，升级后首个请求会错过一次提示缓存。
  • 空响应与不可读模型响应现在会抛出 ModelEmptyResponseError 和 ModelInvalidResponseError，使 FallbackModel 与 ModelFallback 在默认 fallback_on 下对其回退。
  • 默认 fallback_on 下，FallbackModel 与 ModelFallback 现会在空流、缺少 choices 的 OpenAI Chat completion、以及非 JSON 或不符合 schema 的 OpenAI Chat 响应体上回退，而此前会抛出 UnexpectedModelBehavior。两个新错误均继承 ModelAPIError 与 UnexpectedModelBehavior。
  • Pax 的 /permissions 审批改为通过带 token 的 HandleDeferredToolCalls 处理器结合 harness approval_ask 处理；pydantic_ai_pax.runtime.permissions.approval_handler 仍返回 ApprovalHandler，但其处理器现接收 resume token。
  • 会话中各请求共享同一个 instructions 字符串，不再每请求保留副本；ModelMessagesTypeAdapter 现使用 AfterValidator 构建，history 中 instructions 相等的请求持有同一字符串对象，类型、JSON schema、序列化与校验值不变。
  • Coder 配合 SubAgents 时，仅在模型 profile 设置 delegates_unprompted（OpenAI 的 gpt-* 模型，gpt-oss 除外）时发送不主动创建子代理的指令；位于 FallbackModel 之后时不发送，并发出一次 UserWarning。相关 PR 编号包括 #11837、#12108、#13195、#13308、#13764。

分析

  • 新增的 ModelEmptyResponseError 与 ModelInvalidResponseError 使回退机制覆盖更多模型异常场景，但由于两者同时继承 UnexpectedModelBehavior，现有异常捕获逻辑的语义会发生变化，需注意 except ModelAPIError 的位置。
  • instructions 字符串共享属于内存层面的优化，对外类型与序列化行为保持不变，但比较逻辑应使用 == 而非 is。
  • 持久化运行新增 realpath 调用意味着升级窗口内需协调在途任务，Temporal 与 DBOS 用户有相应的版本化手段。

不确定性

  • RepoContext(autoload_instructions=False) 配合嵌套指令文件时，首次请求错过提示缓存的性能影响程度未量化。
实体：pydantic、pydantic-ai、RepoContext、Skills、Memory、FallbackModel、ModelFallback、Coder、Pax产品：pydantic-ai v2.75.0、RepoContext、Skills、Memory、FallbackModel、ModelFallback、Coder、Pax主题：ai_coding、open_source_ai

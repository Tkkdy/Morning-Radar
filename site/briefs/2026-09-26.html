为什么重要：v2.50.0 在决策模型（DecisionModel）上做了较多接口调整，包括路由命名、上下文结构与阈值参数，可能影响依赖决策模型路由行为的调用方。

不确定性：发布说明中的 gemini-3.8-live 与 gemini-3.8-live-extended-thinking 模型名称为原文表述，未在输入中提供更多来源验证。

查看详情

已验证事实

  • 兼容性变更包括：让 DecisionModel 按路由名称询问走哪条路由，每条路由对应一个 label（PR #8733）；使 ModelSelectionContext.messages 以正在被路由的请求结尾，并新增 ModelSelectionContext.prompt（PR #8737）；用可选的 decision_route_threshold 替换决策模型的 tool-call lean（PR #8739）。
  • 新增功能包括：在 provider details 中暴露 OpenAI service_tier（PR #7945）；新增 DecisionModel 作为 Decisions 协议模型的基类，并将 TypeSafeModel 改为其子类（PR #8696）；新增 RunContext.in_durable_context，使 hook 能判断自身运行在 durable workflow 代码中（PR #8723）；新增 gemini-3.8-live 与 gemini-3.8-live-extended-thinking 实时支持（PR #8393）。
  • 其他新增功能包括：在 route premise 下以路由问题询问 DecisionModel 的路由字段，支持嵌套字段 context，并在工具调用后进入 done 状态（PR #8749）；为 DecisionModel 发送的每个请求发出 decide span（PR #8698）。
  • Bug 修复包括：在 mypy 下保留传给 Agent.run 的泛型 OutputSpec[T] 的类型变量（PR #8730）；在 history decision models 判断时发送 ThinkingPart（PR #8738）；将 Anthropic 一小时缓存写入按一小时费率而非五分钟费率计价（PR #8666）；将 realtime 图像输入按图像费率计价（PR #8741）。
  • 其他 Bug 修复包括：新增 RequestUsage.audio_seconds，使按时长计费的语音模型可被计价（PR #8427）；将决策模型无法填充的 output_type 作为一条路由与其他路由并列提供，并将 ToolCallProposed 重命名为 UnfillableRoute，归入 DecisionHandOff 基类（PR #8744）；在无 input item ID 的 provider 上麦克风连续串流时保持 realtime 用户轮次完整（PR #8746）；回滚 provider 拒绝的 realtime 发送，使 wait_for_reply() 不再挂起（PR #8747）；在 OpenAI Realtime 上对 thinking=False 通过发送 reasoning.effort: 'none' 关闭推理（PR #8753）。
  • 其他 Bug 修复包括：从 genai-prices 获取 Jev 的 context_window，并记录压缩 Jev 对话（PR #8740）；为每个 stream_audio() 视图缓冲五分钟音频，使按说话人节奏播放能获得完整回复（PR #8750）；阻止 Google Search 使 Gemini 2.5 native-audio realtime 会话崩溃（PR #8751）；在输入转写关闭时，将用户语音排除在 Gemini 3.x realtime 历史之外（PR #8754）；将失败的 OpenAI realtime 响应错误作为 RealtimeSessionErrorEvent 暴露（PR #8752）。
  • 完整变更日志链接为 https://github.com/pydantic/pydantic-ai/compare/v2.49.0...v2.50.0。
  • 该仓库 stars 数为 20179，forks 数为 2784，open issues 数为 976；24 小时 stars 增量为 22，7 天 stars 增量为 147。

分析

  • 该版本对实时（realtime）与语音场景做了多项修复，包括音频缓冲、计价、历史与错误事件处理，显示项目在持续完善实时多模态支持。

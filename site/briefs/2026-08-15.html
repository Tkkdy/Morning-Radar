Cloudflare 检测 MCP 流量并帮助保护其安全

Cloudflare Gateway 通过协议级别的启发式方法识别 MCP 请求，使安全团队能够发现影子 MCP 流量，强制仅通过 Portal 访问已批准的服务器，并在受管网络路径上阻止直接连接。

为什么重要：随着 MCP 在企业中的采用增加，未经授权的 MCP 流量可能成为数据泄露或策略绕过的通道；Cloudflare 提供的检测与强制访问控制为安全团队提供了一层网络侧防护。

openai-python v3.0.0 发布，HTTP 客户端迁移至 HTTPX2

OpenAI 官方 Python SDK 发布 v3.0.0 版本，将默认 HTTP 客户端从 httpx 迁移至 HTTPX2，旧版 httpx 不再自动安装，自定义配置需迁移。

为什么重要：此破坏性变更要求所有使用自定义HTTPX组件的项目必须升级，可能引发大面积代码兼容性问题，影响众多AI应用。

已上线
GitHub · openai/openai-python · Release 主来源 Release 发布于 2026-08-12

不确定性：临时逃生口有效期未明确，未来版本可能移除；尚不清楚现有项目受影响的范围以及迁移难度。

查看详情

已验证事实

  • openai-python v3.0.0 于 2026 年 8 月 12 日发布。
  • HTTPX2 成为默认 HTTP 客户端，httpx 不再自动安装。
  • 使用自定义 HTTPX 客户端、传输层或配置对象的应用程序必须迁移至 HTTPX2 等效方案，或使用临时的运行时旧版 HTTPX 逃生口。
  • 此次变更属于破坏性变更（BREAKING CHANGES）。
  • 相关迁移指南参见 HTTPX2 迁移文档。

分析

  • 此次重大版本更新强制开发者将 HTTP 客户端升级至 HTTPX2，可能对依赖旧版 httpx 的集成产生广泛影响。
  • 对于自定义了 HTTPX 组件的用户，迁移成本较高；使用默认客户端的项目影响相对较小。
  • openai-python 作为 OpenAI 官方 Python SDK，此举反映了基础设施现代化和维护简化趋势。

不确定性

  • 尚不清楚有多少现有项目直接依赖了自定义的 httpx 配置或传输对象，迁移过程可能导致部分功能中断。
  • 临时逃生口的具体有效期和支持程度未明确说明，可能在未来版本中移除。
实体：OpenAI产品：openai-python主题：AI编程、开源AI

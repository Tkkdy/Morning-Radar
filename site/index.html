已验证事实

  • 该版本为 ConversationStore 增加 SQLite、Postgres 和 MongoDB 后端，并将 Pax session store 重命名为 SqliteSessionStore（对应 PR #10473）。
  • pydantic_ai_harness.step_persistence.conversations 中的 SqliteConversationStore 和 ConversationConflict 分别重命名为 SqliteSessionStore 和 SessionConflict，旧名称仍可导入但会触发 HarnessDeprecationWarning。
  • 该版本默认跳过缺失或不可读的技能库与技能，新增 SkillCatalog.advice，并让 pax 技能文件夹按最近目录优先搜索（PR #10524）。
  • 不带 missing_directories 的 Skills(...) 现在会跳过缺失、非库或不可读的库路径并给出警告；传入 missing_directories='error' 可保持失败行为；不可读的技能目录或 SKILL.md 会被跳过，而不是抛出 PermissionError；SkipReason 新增一个取值。
  • 该版本新增 thinking_summary 以跨提供方返回可读的思考内容，并新增 anthropic_thinking_display 与 bedrock_thinking_display（PR #11084）；在 Anthropic 及 Bedrock 上的 Claude，设置统一 thinking 设置的请求会发送 thinking.display: 'summarized'。
  • 该版本新增 compact_history() 能力钩子、RunContext.request_compaction() 和一方压缩事件（PR #11454）；AgentStreamEvent 新增 CompactionStartEvent 与 CompactionEndEvent，仅在调用 request_compaction() 或存在 compact_history 钩子时发出。
  • 该版本使 SubAgents 跳过低于 'operator' 权限的磁盘子代理，并为 working_directory 委托保留父级权限（PR #11839）；使用 SubAgents 与 agent_folders 的持久化运行会在运行开始时为每个代理定义文件记录一个 realpath。
  • 该版本在自动 SummarizingCompaction 失败时保持父运行存活（PR #12655）；默认 FallbackCompaction 链现可从 UnexpectedModelBehavior 恢复。
  • yogeshwaran10 在 PR #13551 中完成其首次贡献；默认 google_api_key 密钥模式现也会脱敏 AQ. 后跟 40 到 200 个密钥字符的内容。
  • 该版本对被流式响应在提供方终止事件之前结束的情况报告 'incomplete'（PR #14086）。
  • 该仓库当前有 21434 个 star、3301 个 fork、2173 个 open issues。
  • 该版本发布说明中被截断的条目以 'The final `stream_resp' 开头，内容不完整。

分析

  • thinking_summary 与 thinking.display: 'summarized' 的引入反映 pydantic-ai 在跨提供方统一推理内容呈现上的抽象层持续加深，同时提示可能带来首个文本 token 前的额外延迟。
  • 压缩能力从自动 SummarizingCompaction 扩展到可编程的 compact_history 钩子与显式事件，表明长会话上下文管理正在成为该框架的一等能力。
  • 跳过低于 'operator' 权限的磁盘子代理以及对 working_directory 委托降权，体现默认安全边界的收紧。
  • 持久化运行在启动时记录 agent 定义文件的 realpath，与升级建议（等待在途运行完成或使用 Temporal worker 版本化 / 新的 DBOS 应用版本）共同说明本次升级需要运维侧配合。

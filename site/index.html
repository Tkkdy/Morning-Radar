Ollama v0.40.14：Claude Code 输出 token 限制与云端连接鲁棒性修复

Ollama 发布 v0.40.14（变更范围 v0.40.13 至 v0.40.14）。`ollama launch claude` 现在会对 Claude Code 应用模型的输出 token 限制，使云端模型不再受 128k 默认上限影响；`/api/chat` 上的云端网页搜索响应可被正确解码（包括压缩响应）；OpenAI 兼容端点不再覆盖模型内置采样器默认值，未发送 `temperature`/`top_p` 的客户端会使用模型自身取值而非 1.0，与 `/api/chat` 行为一致；`/v1/responses` 保留可读输入内容（包括此前的助手拒答），不再扁平化；Ollama 应用可重试 ChatGPT 断连失败；`ollama launch codex` 在配置前验证 ChatGPT 路由并报告明确错误；MLX 上大词表的 top-k 采样速度提升。

状态推进

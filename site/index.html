googleapis/python-genai v3.0.0 发布：默认 API 版本改为 v1，默认 HTTP 客户端改为 httpx2

googleapis/python-genai 发布 v3.0.0，Gemini Developer API 的默认 API 版本由 v1beta 改为 v1，使用 vertexai=True 或 enterprise=True 的客户端不受影响，继续默认使用 v1beta1。gemini-flash-latest、gemini-flash-lite-latest 和 gemini-pro-latest 仅在 v1beta 上可用，可通过环境变量 GOOGLE_GENAI_API_VERSION 或 HttpOptions 的 api_version 参数调整。另一项破坏性变更是默认 HTTP 客户端由 httpx 改为 httpx2，httpx 不再默认安装。

为什么重要：依赖 latest 别名或 httpx 类型对象的调用方在升级后可能出现模型不可用或类型、异常处理不一致的问题，需要显式固定版本或切回旧默认值。

  • v3.0.0 的主要破坏性变更之一：Gemini Developer API 的默认 API 版本由 v1beta 改为 v1。
  • 使用 vertexai=True 或 enterprise=True 的客户端不受该默认值变更影响，继续默认使用 v1beta1。
  • gemini-flash-latest、gemini-flash-lite-latest 和 gemini-pro-latest 仅在 v1beta 上可用，在 v1 上不可用。
  • 可通过设置环境变量 GOOGLE_GENAI_API_VERSION 配置或恢复默认 API 版本。
  • 可在代码中通过 HttpOptions 的 api_version 参数设置 API 版本，其优先级高于 GOOGLE_GENAI_API_VERSION。
  • 另一项破坏性变更：默认 HTTP 客户端由 httpx 改为 httpx2，且 httpx 不再默认安装。
  • 若需恢复 httpx 作为默认客户端，需安装 google-genai[httpx] 并设置 GOOGLE_GENAI_HTTP_CLIENT=httpx。
  • 多数情况下，将现有 httpx 代码迁移到 httpx2 只需改为 import httpx2 as httpx。
  • 当 SSL_CERT_FILE 和 SSL_CERT_DIR 未设置时，httpx2 默认使用操作系统证书信任存储，而非 certifi。
  • interactions 中 CodeExecutionResultStep.result 的类型由 string 改为 CodeExecutionResultStepResult 联合类型；仅含文本结果的 JSON 不变。
  • 该版本新增 AudioTranscriptionConfig 的 source_text 字段。

分析

  • 默认 API 版本切换至 v1 意味着依赖 latest 别名的调用方在升级后可能无法继续使用这些别名，需要改用具体模型版本或显式切回 v1beta。
  • httpx 与 httpx2 的类型对象（如 Timeout、Limits、Transport 及异常类型）需与当前启用的 HTTP 客户端匹配，混用可能导致类型或异常处理不一致。
  • 从 SDK 使用面看，本次发布同时改变 API 版本默认值与 HTTP 底层依赖，升级影响面较以往版本更宽。

不确定性

  • 输入未说明 v1beta 上这些 latest 别名未来是否会被移除或迁移到 v1。
  • 输入未提供 httpx2 相对于 httpx 的具体性能或功能差异说明。

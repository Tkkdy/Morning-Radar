Canva 发布首个自研 AI 图像模型 Canva Craft，采用两阶段架构先生成设计方案再出图

The Verge AI 报道，Canva 发布了图像生成模型 Canva Craft，这是 Canva 首个自研 AI 图像模型。报道称 Canva Craft 采用两阶段架构，可先规划设计方案再生成图像。报道援引 Canva 的说法称，该架构带来“greater precision, consistency and control”（更高的精度、一致性与可控性）。The Verge AI 还称，该模型直接与 OpenAI、Microsoft 和 Google 的图像生成模型竞争。

openai-python 发布 v3.37.0，带来 Decisions 类型的不兼容变更

openai/openai-python 于 2026-10-22 发布 v3.37.0。该版本包含不兼容变更：在 Live 响应模型中，question 的 instructions 字段现在可以是字符串，也可以是包含文本、图片或 JSON 结构化部件的列表；Decisions 请求的输入类型新增了消息角色和工具历史条目，因此需要相应更新穷举式类型检查。已有的字符串 instructions 和 DecisionInputMessageParam 用户消息输入仍然受支持。此外还包含维护工作：保留 file 与 video 轮询辅助函数、保留上传辅助函数与 Live 连接默认值，以及将 astral-sh/setup-uv 从 10.2.0 升级到 10.3.0。

后续事件

相比此前：openai-python 从 v3.32.0 推进到 v3.37.0，并在 Decisions 类型上引入不兼容变更：question.instructions 现在可为字符串或结构化部件列表，输入类型新增消息角色与工具历史条目。

此前：2026-10-19 · openai-python 发布 v3.32.0，新增缓存设置、基于提示的语音创建与区域处理驻留选项等 API 功能

为什么重要：这是 Python SDK 面向 Decisions API 类型模型的接口约定变更，依赖字符串操作或穷举类型检查的调用方可能需要调整代码。

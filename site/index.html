huggingface/transformers v5.22.0 发布，新增 Mistral Large 4（Le Chonk）模型支持

huggingface/transformers 发布 v5.22.0，新增对 Mistral Large 4（Le Chonk）模型的支持。

为什么重要：该发布说明同时覆盖模型能力介绍与 transformers 库自身的工程变更（FP8 训练支持、EP 逻辑拆分、CI 镜像调整），因此这条发布既是模型发布信号，也是库版本更新信号。

已上线
GitHub · huggingface/transformers · Release 主来源 Release 发布于 2026-10-29

不确定性：发布说明中的性能表述（如“超越前沿闭源模型的视觉定位能力”“开放权重模型中的最先进水平”）来自 Mistral 与发布说明作者，本文未提供独立基准或第三方评测结果加以验证。

查看详情

已验证事实

  • 根据发布说明，Mistral Large 4 是 Mistral 迄今规模最大、能力最强的模型：总参数约 1 万亿，为原生多模态 Mixture-of-Experts 模型，每 token 激活参数约 490 亿（含嵌入和输出层为 520 亿）。
  • 发布说明称，该模型从零训练于 Mistral 在欧洲自有数据中心的 3800 块 NVIDIA Grace Blackwell GPU 上。
  • 发布说明称，Mistral Large 4 采用 128 个路由专家（每 token 激活 4 个）加 1 个共享专家的 MoE 结构，上下文长度为 1M，支持文本与图像输入、文本输出。
  • 发布说明称，该模型支持可配置的推理强度（low/medium/high，默认 high）、原生函数调用、JSON 输出与严格的 JSON schema 约束，并原生支持 160 多种语言，包括欧盟全部官方语言。
  • 发布说明称，该模型以 Mistral Ecosystem Open-Weight License 发布，该许可证是 MIT 许可证的修改版，允许商业和非商业使用；以模型即服务方式运营需要与 Mistral 单独签订商业许可。
  • v5.22.0 的破坏性变更为将 EP 逻辑拆分至独立文件（#49679）。
  • 该版本量化相关更新包括：支持在 FP8 量化模型上进行适配器训练（如 PEFT 的 LoRA）（#50031），以及在稠密与分组 FP8 矩阵乘法中加入反向传播；发布说明称在 8k token 下 MoE 层反向传播的峰值内存从约 28.9 GiB 降至 2.8 GiB（#50117）。
  • 该版本的另一项更新为在 AMD CI 镜像中安装 onnxscript、bitsandbytes 和 peft。

分析

  • 发布说明将 FP8 反向传播的内存优化定位为适配器训练可行性的关键突破，这表明在量化权重之上进行微调是该版本的主要工程方向。

不确定性

  • Mistral Large 4 的实际可用性、托管渠道与定价未在输入中说明。
  • 发布说明中“3800 块 GPU 训练”“1M 上下文”等具体指标仅来自单一官方来源，尚无其他来源交叉印证。

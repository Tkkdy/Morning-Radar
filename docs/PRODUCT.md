# 产品范围

## 产品定位

Morning Radar 是个人 AI 科技、资本市场和开发者生态情报系统，不是把新闻标题简单堆叠
在一起的阅读器。它每天回答过去 24 小时发生了什么、为什么重要、不同来源是否互相印证、
哪些信号正在连续升温，以及哪些结论仍需观察。

## v0.1 用户价值

用户可以通过一份短中文晨报同时查看：

- 重要事件及其可追溯来源；
- 重点公司的最近交易日表现（仅作信息展示）；
- GitHub 项目发布和可解释的短期增长；
- Hacker News 等开发者讨论信号；
- 有足够跨日和多来源证据时才生成的趋势观察。

## 产品原则

1. 少而重要，热度不等于重要性。
2. 同一事件只展示一次，多个来源合并为证据。
3. 事实、分析、观点和不确定性明确分开。
4. GitHub Star 不代表真实采用，股价变化不归因于单一新闻。
5. 没有足够证据时不生成趋势或方向判断。
6. 哲学或认知延伸内容可以为空，不为填充版面而编造。
7. 所有公开链接来自采集输入，AI 无权创建链接。

## 明确不做

v0.1 不做第二个 AI Provider、多模型投票、多智能体、用户注册登录、后台管理、
移动 App、收藏点赞、全文搜索、周报月报、分钟级监控、全市场扫描、价格预测、
投资建议、受保护平台抓取、反验证码、代理池、知识图谱和向量数据库。

## 成功标准

Fixture 模式可在没有网络和密钥的环境完整生成站点；生产模式可通过环境变量启用真实
采集、OpenAI 和 WxPusher；全部测试与 Ruff 通过；GitHub Actions 可定时或手动运行并
发布 GitHub Pages；重复运行不会重复推送；README 和 HANDOFF 足以让初学者完成部署。

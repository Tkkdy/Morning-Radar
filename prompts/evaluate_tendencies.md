Evaluate whether independent, cross-event evidence supports a falsifiable
structural Tendency. Tendency is not topic or keyword clustering: every decision
must state one shared mechanism that explains how the events are changing real
behavior, products, workflows, or institutions.

Treat each evidence cluster as one independent event boundary. Source count is
corroboration, not additional independent evidence. Candidate is internal;
Emerging is the first public standing. Formation normally expects about three
clusters, while a two-cluster exception requires different actors, strong primary
evidence, observable impact, and an explicit exception rationale. Consider the
baseline, a future falsifier, and counterevidence.

For an existing Emerging or Persistent Tendency, use only genuinely new clusters
after formation for survival. Time passing and absence of news are not updates.
Formation evidence cannot prove persistence again. One contrary event normally
means weakened, not overturned. Revised keeps the same existing_tendency_id and
must express the changed claim. Overturned requires the core claim to be
invalidated. Omit decisions when there is no new meaningful evidence.

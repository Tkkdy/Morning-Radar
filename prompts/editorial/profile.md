# VDVXDV Editorial Profile v1.0 (portable)

Morning Radar developer-first, not developer-only。优先关注会实质改变模型能力、价格、配额、
可靠性、Coding Agent、API、开发工具、生产 workflow、open weights、本地部署和普通硬件可用性
的变化。真实 practitioner evidence、独立复现、透明方法和实际部署优先于公司名气和官方
benchmark。

TOP 是今天最重要的事实；STORY 值得解释机制和后果；NEWS 值得知道但无需长分析；ONE-LINER
一句即可；SUPPORT 只服务于另一事件；DROP 不占读者注意力，但可以保留为趋势证据。

Reader placement 与 evidence retention 是两个独立判断。`retain_for_trends` 不表示是否把 Story
保存到磁盘——所有 Story 本来都会保存；它表示该 Story 是否应成为当前或未来 Trend、
Tendency 或 Prediction Evaluation 的显式证据。能支持、削弱或反转既有趋势，可能在后续
adoption、复现或失败后变得重要，记录能力、开源、本地部署、许可证、价格、可靠性、
基础设施、市场结构、安全或政策实际影响演化，或可验证过去判断与因果解释的信息，通常应
保留。可信 weak signal 即使只值 ONE-LINER 或 DROP，也可以前台低、后台高。

装饰性更新、普通维护、无结构意义的宣传、已经完全解决且没有持续后果的短暂故障，以及
无法命名潜在趋势或未来验证用途的噪声，通常不保留。保留时使用清晰、可复用的具体
`trend_links`，不要使用“AI 发展”“行业趋势”等空标签。叙述说要保留为趋势线索时，结构字段
也必须设为保留。

政府声明、voluntary framework 和抽象监管默认只作后台证据，只有已展示对开发能力、成本、
工具、支付、云部署或自动化的实际影响才提升。异常市场波动本身可获高注意力，但必须把已
确认的价格事实与低可信因果解释分开。一个真实事件只呈现一次，市场反应和后续材料通常作为
SUPPORT。前台保持两到三分钟可读，后台判断可以更丰富。
